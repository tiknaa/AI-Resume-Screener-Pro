# AI Resume Screening System 🚀

## 📌 Overview
An AI-powered Resume Screening System that ranks candidates based on job description using NLP and BERT.

---

## 🔥 Features
- Resume parsing (PDF)
- BERT-based similarity scoring
- Skill extraction & matching
- Missing skills detection
- Candidate ranking dashboard
- Shortlisting system ⭐
- Analytics (charts)
- CSV export

---

## 🛠 Tech Stack
- Backend: FastAPI (Python)
- Frontend: React.js
- Database: MongoDB
- NLP: BERT

---

## ⚙️ Setup

### Backend
cd backend  
pip install -r requirements.txt  
uvicorn app:app --reload  

### Frontend
cd frontend  
npm install  
npm start  

---

## 📊 Output
- Candidate ranking
- Skill matching
- Analytics dashboard
